Подключение ESP32-S3 KVM

Плата втыкается в USB целевого ПК и становится его клавиатурой и мышью. Управление идёт по Wi-Fi через Tailscale, поэтому проводов почти нет: USB к ПК и, по желанию, USB-UART для логов.

ESP32-S3 SuperMini

Сборка с sdkconfig.defaults.supermini. Разъём USB-C платы — это нативный USB (GPIO19/20), он занят HID. Логи выводятся только на UART0: TX = GPIO43, RX = GPIO44, 115200.

Наведите или нажмите на провод или строку таблицы — соединение подсветится. Esc — сброс.

ESP32-S3 N16R8 (DevKitC-1)

Сборка с sdkconfig.defaults.n16r8. У платы два разъёма: USB (нативный) идёт к целевому ПК, COM (UART через мост на плате) — к Mac для логов. Отдельный адаптер не нужен.

Наведите или нажмите на провод или строку таблицы — соединение подсветится. Esc — сброс.

Разъём платыКудаЗачем
USBUSB целевого ПКклавиатура и мышь, питание

Прошивка по кабелю

  1. SuperMini: зажмите BOOT, подключите USB-C к Mac, отпустите BOOT. N16R8: можно прошивать через разъём COM без кнопок.
  2. idf.py -B build -p /dev/cu.usbmodemXXXX flash (порт смотрите в ls /dev/cu.*).
  3. Нажмите RST или переподключите кабель, затем подключите плату к целевому ПК.
Важно
  • Кабель USB должен передавать данные, а не только питание.
  • У USB-UART адаптера подключайте только TX, RX и GND: плата уже питается от USB целевого ПК.
  • Удержание BOOT 5 секунд в рабочем режиме стирает настройки и ключи Tailscale.
